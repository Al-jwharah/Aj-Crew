# Code of Conduct

This project follows the [Amazon Open Source Code of Conduct](https://aws.github.io/code-of-conduct),
the standard of behaviour it inherited from the upstream project. The
[Code of Conduct FAQ](https://aws.github.io/code-of-conduct-faq) explains how to read it.

Aj Crew is an independent fork and is not an Amazon project. Amazon does not handle conduct
reports about this repository, so do not send them to the address those pages list. Report a
concern to the maintainer, [@Al-jwharah](https://github.com/Al-jwharah), privately through the
contact details on that GitHub profile. Abuse that happens on GitHub itself can also be reported
to GitHub with the "Report content" option on the comment, issue or profile concerned.
