# Security Policy

## Reporting a Vulnerability

If you discover a potential security issue in this project, please **do not** create a public
GitHub issue. Instead, report it privately:

- **Private advisory:** open a report at
  <https://github.com/Al-jwharah/Aj-Crew/security/advisories/new> (GitHub's private
  vulnerability reporting for this repository).

Please include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

Reports are handled on a best-effort basis by the maintainer of this fork.

### Issues that also affect upstream

Aj Crew is a fork of [Kiro Crew](https://github.com/kirodotdev/KiroCrew). If the issue is in
code this fork inherited unchanged, it very likely affects upstream too. Upstream has its own
contact, which does not handle reports about this fork:
[kiro-crew-security-support@amazon.com](mailto:kiro-crew-security-support@amazon.com).

## Supported Versions

Only the latest release is actively supported with security patches. We recommend always
running the most recent version.

## Scope

This policy covers the Aj Crew source code and its bundled dependencies. It does not cover
third-party services (LLM providers, etc.) that Aj Crew connects to.
